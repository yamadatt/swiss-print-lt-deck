09 / Why it fits

サーバレスの3つの特徴

  • サーバ管理が不要
    • OS・パッチ・スケールは Lambda / DynamoDB に任せる
  • 使った分だけの従量課金
    • Lambda はリクエスト数 × 実行時間、DynamoDB は読み書き量で計算
  • 自動でスケールする
    • アクセスに応じて Lambda が並列起動 / アイドルは無料

11 / Code
書くのは
「関数」だけ
サーバの起動もポート待ち受けも 書かない。
Go の関数を Lambda にデプロイすればAPIになる。
main.go
package main

import (
  "github.com/aws/aws-lambda-go/events"
  "github.com/aws/aws-lambda-go/lambda"
)

// API Gateway からのリクエストを受けて返すだけ
func handler(req events.APIGatewayProxyRequest) (events.APIGatewayProxyResponse, error) {
  name := req.QueryStringParameters["name"]
  return events.APIGatewayProxyResponse{
    StatusCode: 200,
    Body:       `{"message":"Hello, ` + name + `!"}`,
  }, nil}

func main() { lambda.Start(handler) }

15 / Key points

知っておきたい注意点

01
コールドスタート
久々の起動は数百msほど遅くなることも。
常に低レイテンシが要る用途は要検討。
02
ベンダーロックイン
各クラウドの流儀に乗る。乗り換えコストは上がる。
個人開発なら許容しやすい。
03
ローカル開発の工夫
手元で動かす環境づくりがひと手間。
LocalStack などのエミュレータやIaCで再現性を確保する。
