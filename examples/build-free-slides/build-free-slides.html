07 / Key points

HTMLにして効いた3つ

01
環境を用意しなくていい
当日の会場PCでも、ファイルを開くだけで動く。
発表直前にビルドが通らない事故が起きません。
02
差分が読める
テキストなので Git の diff がそのまま効く。
「どこを直したか」が後から追えます。
03
デザインを固定できる
配色も文字サイズも CSS 変数に集約。
毎回デザインで迷わずに済みます。
