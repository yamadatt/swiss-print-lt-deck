07 / Code
書くのは
これだけ
コードは 1画面に収まる量 まで削る。
読ませたい行だけ左の赤罫で示す。
main.go
package main

import (
  "context"
  "golang.org/x/sync/errgroup"
)

// 逐次で待つと遅い。まとめて待つ
func fetchAll(ctx context.Context, ids []string) error {
  g, ctx := errgroup.WithContext(ctx)
  for _, id := range ids {
    g.Go(func() error { return fetch(ctx, id) })
  }
  return g.Wait()}

17 / Steps

導入までの4ステップ

Step 01
計測する

Step 02
特定する

最小の変更で直し、もう一度計測する。
Step 04
自動化する
ベンチをCIに載せ、回帰に気づける状態を残す。

20 / Pitfalls

ありがちな落とし穴

Don't
いきなり直す
  • 推測でチューニングを始める
  • 全部を一度に直そうとする
  • 手元のマシンだけで計測する
Do
測ってから直す
  • プロファイラの数字から始める
  • 一番太いボトルネックだけ直す
  • CIで継続的に計測する
